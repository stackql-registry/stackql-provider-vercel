Returns a stream of logs for a given deployment.

```sql
SELECT
contents
FROM vercel.deployments.runtime_logs
WHERE project_id = '{{ project_id }}' -- required
AND deployment_id = '{{ deployment_id }}' -- required
AND team_id = '{{ team_id }}'
AND slug = '{{ slug }}'
;
```
