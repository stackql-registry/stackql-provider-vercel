Retrieve feature flag settings for projects in a team.

```sql
SELECT
owner_id,
project_id,
type_name,
created_at,
enabled,
entities,
environments,
metadata,
updated_at
FROM vercel.feature_flags.team_settings
WHERE team_id = '{{ team_id }}' -- required
AND limit = '{{ limit }}'
AND cursor = '{{ cursor }}'
AND slug = '{{ slug }}'
;
```
